# *Coño, otra vez no...*

El momento en que vi Electron por primera vez fue como cuando Rentaro conoce a una nueva alma gemela, pero a la *inversa* en plan tortura mental. O sea, si estás trabajando con HTML, CSS y JS, que literalmente están hechos para los navegadores mórbidamente obesos que tenemos, ¿¡por qué carajo tienes que convertirlo en una app de escritorio!? ¿Cuál es el punto de descargar la app de Discord si hace exactamente lo mismo que el Discord del navegador, y peor porque se desayuna mi PC sin motivo alguno? ¿Cuál es el punto de descargar la app de Spotify si no puedo ponerle un bloqueador de anuncios y algunos temas de CSS al azar *porque* no está en mi navegador, y ahora necesito 8GB de memoria extra? Después te dicen que si *"ah no marico comprate mas computadora que esa ya está vieja"* mano, entiéndeme que no todo el mundo tiene la oportunidad ni está dispuesto a tirar un chorro de plata en una computadora nueva que se va a según quedar *"obsoleta"* dentro de 2 años, ni que fuera enchufado para hacer eso! Esto es una tontería.

Y la experiencia de usuario también es importante, pues muchos programadores no piensan en los mismos usuarios que van a utilizar su producto y en vez de poner un *Releases* bien hecho te andan tirando un rtfm de 300 páginas para usar seis contenedores de docker, dos scripts de python y un .sh que ni sirve.
